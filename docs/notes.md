# Заметки

`POST /api/notes` принимает JSON `{"text":"заметка"}` и возвращает созданную
запись с id и created_at (201). `GET /api/notes` возвращает до 100 последних
записей, сначала новые. Текст обрезается по краям, длина — 1–2000 символов.

`DATABASE_URL` передаётся из ключа `url` Secret `postgres-credentials`.
При старте создаётся таблица `app.notes`; схема и прикладная роль подготовлены
Helm chart из `environment`. Пароль и ошибки подключения не выводятся в HTTP.

`/health` проверяет процесс, `/readyz` — доступ к БД. Без DATABASE_URL или
при недоступной БД readiness и методы заметок возвращают 503.
Версия API — 0.2.0. CI проверяет API с настоящим PostgreSQL на amd64 и arm64.
Локально интеграционный тест включается переменной `TEST_DATABASE_URL`.
